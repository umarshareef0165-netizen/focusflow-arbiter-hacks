# FocusFlow demo video script (target 2:30, for Umar to record — NOT recorded yet)

Real screen capture only. No credentials, keys, or other people's data in any frame.
No seeded numbers: use tasks and focus time created live during the recording.

- 0:00–0:15 — One sentence: "FocusFlow is an offline study planner that counts
  only real work — no account, no cloud, no fake stats."
- 0:15–0:45 — Add two tasks with minutes, show the progress bar at 0%.
- 0:45–1:15 — Click Complete on one task; show the task struck through, progress
  updating, and the next task named.
- 1:15–1:50 — Start the focus timer, let it run visibly, pause it, and show the
  focused-minutes total. Say plainly: paused time does not count.
- 1:50–2:15 — Restart the app (or refresh after a restart in the recording) and
  show the same tasks and focus total still there — local JSON persistence,
  nothing lost, nothing invented.
- 2:15–2:30 — Close: offline by design, Python stdlib only, public repo link on
  screen, and the honest limit — it counts timer time, not attention itself.
